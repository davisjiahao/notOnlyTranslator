### 1.1 直接竞品（同类英语学习/翻译浏览器插件）

#### 沉浸式翻译 (Immersive Translate)

| 维度 | 详情 |
|------|------|
| **核心定位** | 双语对照翻译，整页/段落翻译 |
| **目标用户** | 所有需要阅读外文内容的用户（泛用型） |

## 三、竞争格局总结

### 市场地图

```
                    翻译质量优先
                        │
              DeepL ────┼──── Google/Microsoft
                        │
    ────────────────────┼────────────────────
    学习导向              │              泛用导向
                        │
   沙拉查词 ────────────┼──── 沉浸式翻译
   Yomitan              │
   Anki 组合            │         ChatGPT/Claude
                        │
                    notOnlyTranslator
                    (按水平翻译)
```

**核心洞察**：notOnlyTranslator 在"学习导向 × 个性化翻译"象限几乎没有直接竞品。沉浸式翻译和沙拉查词分别在"泛用翻译"和"查词工具"两个方向上领先，但都没有"根据学习者水平动态翻译"的能力。这是我们的护城河。

**主要威胁**：
1. 沉浸式翻译如果加入"难度分级翻译"功能，将直接冲击我们
2. 沙拉查词的 Anki 集成已经建立了学习工具信任
3. ChatGPT/Claude 的通用 AI 能力可能覆盖我们的翻译场景
