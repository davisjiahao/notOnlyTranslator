## UX 审计：Tooltip 交互（tooltip.ts + index.ts）

### 严重问题 🔴

1. **console.log 残留在生产代码中** (`index.ts`)
   - 行 478-479: `console.log('[NotOnlyTranslator] Global set:...')`
   - 行 821-823: `console.log('[NotOnlyTranslator] Loading settings...')`
   - 行 1718/1723/1728/1734: sendMessage 中的 debug log
   - **影响**: 违反项目规则，泄漏内部信息到用户控制台
   - **建议**: 全部替换为 `logger.info/debug` 或删除

2. **Tooltip 定位使用 inline style** (`tooltip.ts:632-633`)
   - `this.element.style.top = ...` / `this.element.style.left = ...`
   - **影响**: 无法被 Tailwind 覆盖，且 CSS 优先级过高
   - **建议**: 使用 CSS custom properties (`--tooltip-top`, `--tooltip-left`) 或 `transform: translate()`

3. **Help 面板使用 inline style** (`tooltip.ts:111-112, 173-174`)
   - `panel.style.display = 'none'` / `this.helpPanel.style.top = ...`
   - **影响**: 同上，不符合 Tailwind CSS 规范

### 中等问题 🟡

4. **双击清除用户选区** (`index.ts:109`)
   - `selection.removeAllRanges()` 在双击后立即执行
   - **影响**: 用户双击后看不到文字选中效果，可能困惑
   - **建议**: 延迟清除或保留选区直到 tooltip 显示

5. **临时定位元素影响 DOM** (`index.ts:1050-1055, 1449-1453`)
   - 创建临时 `span` 元素用于 tooltip 定位
   - **影响**: 可能触发现有 MutationObserver，干扰页面
   - **建议**: 使用 `data-notranslate` 标记临时元素，或在 observer 中过滤

6. **Pin 按钮使用 Emoji** (`tooltip.ts:303, 307`)
   - 📌/📍 作为图标，跨平台渲染不一致
   - **建议**: 使用 SVG 图标保持一致性

### 低优先级 🟢

7. **Tooltip 无进入/退出动画** (`tooltip.ts:456, 571`)
   - 仅通过 class toggle 显示/隐藏
   - **建议**: 添加 CSS transition (`opacity`, `transform`) 提升感知性能

8. **滚动隐藏延迟 300ms 可能过短** (`tooltip.ts:273`)
   - 快速滚动时 tooltip 频繁闪烁
   - **建议**: 可配置化，或使用 scrollEnd 事件
