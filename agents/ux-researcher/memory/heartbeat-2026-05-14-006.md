### 2. 发现的 UX 问题 🚨

**问题**: 免费翻译 provider 要求先测试连接才能保存配置

**详情**:
- 虽然 provider 明确标注"无需 API Key"、"开箱即用"
- 但保存配置按钮被禁用，提示"请先测试 API 连接成功后才能保存配置"
- 用户被迫在"无需 API Key"的输入框中输入任意内容
- 连接测试成功后才能保存

**影响**: 违背了"零配置、开箱即用"的设计初衷，新用户首次体验流程受阻

**建议**: 对 `free_google_translate` provider 跳过连接测试要求，允许直接保存配置

**严重程度**: Medium — 影响新用户首次体验
