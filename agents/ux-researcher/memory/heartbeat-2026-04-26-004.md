#### 关键实现细节

**ApiSwitcher 键盘导航**:
- 触发按钮使用 `role="combobox"` + `aria-haspopup="listbox"` + `aria-expanded`
- 下拉列表使用 `role="listbox"`，选项使用 `role="option"` + `aria-selected`
- ArrowDown/ArrowUp 循环遍历，Enter/Space 选择，Escape 关闭并恢复焦点
- 聚焦选项有 `outline outline-2 outline-primary-500` 视觉反馈（WCAG 2.4.7）
- 点击外部区域自动关闭

**MasteryCard 可点击区域**:
- `<div onClick>` → `<button>` + `aria-expanded` + `aria-label`
- 移除 `border-0 bg-inherit` 保持视觉一致

**Options 侧边栏 Tabs 模式**（WAI-ARIA Authoring Practices 标准实现）:
- `<nav aria-label="设置导航">` 标识导航 landmark
- `<ul role="tablist" aria-orientation="vertical">` 容器声明纵向 tab 列表
- 每个 tab 按钮：`role="tab"` + `id="tab-${tab.id}"` + `aria-selected` + `aria-controls="tabpanel-${tab.id}"` + `tabIndex={active ? 0 : -1}`（roving tabindex 模式）
- ArrowUp/ArrowDown 循环切换、Home/End 跳转首尾，自动同步 `setActiveTab` + 焦点
- 主内容区 `<main role="tabpanel" id="tabpanel-${activeTab}" aria-labelledby="tab-${activeTab}" tabIndex={0}>` 让屏幕阅读器关联 tab 与面板
