# UX Researcher Heartbeat - 2026-05-01 第1次检查

## 本次工作

### ✅ UX 改进 — 移除 `alert()` 反模式 (29e4c69)

在 `VocabularyExportImport.tsx` 中发现 2 处 `alert()` 调用：
1. 导出词汇为空时 — `alert('没有符合条件的词汇可导出')`
2. 导出失败时 — `alert('导出失败：' + error.message)`

**问题**：浏览器原生 `alert()` 破坏视觉一致性、不支持暗色模式、阻塞主线程。

**修复**：
- 添加 `exportError` 状态
- 替换为带 `role="alert"` 的内联错误提示
- 错误信息在关闭弹窗时自动清除
