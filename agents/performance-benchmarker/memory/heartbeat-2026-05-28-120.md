## Bug 修复 — analyzeFunnel TDZ
- **问题**: `analyzeFunnel` 使用 `.map()` 赋值 `steps`，但在 map 回调内引用 `steps[index - 1]`
- **根因**: JavaScript TDZ (Temporal Dead Zone) — `steps` 在 `.map()` 完成前未赋值
- **影响**: 所有非第一步的转化率计算都会抛 `ReferenceError`，导致 catch 块返回空结果
- **修复**: 将 `.map()` 改为 `for` 循环，顺序计算每个步骤，前一步结果在计算后一步时可用
- **验证**: funnel.test.ts 从 2 failed → 18 passed
