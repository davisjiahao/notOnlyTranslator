## 技术细节

### 组合选择器实现

```typescript
const COMBINED_EXCLUDED_SELECTOR = EXCLUDED_SELECTORS.join(',');

function matchesExcludedSelector(element: Element): boolean {
  try {
    return element.matches(COMBINED_EXCLUDED_SELECTOR);
  } catch {
    return false;
  }
}
```

| 方法 | 100 元素扫描耗时 | 原因 |
