### Work Performed

**Fixed: `useTablistKeyboard` hook focus management bug** (Commit: e3d0939)

The `useTablistKeyboard` hook (added in `77f8015`) updated the active tab state but **never moved focus** to the newly selected tab. Keyboard users pressing ArrowRight/ArrowLeft would see no visual focus change — a **WCAG 2.4.3 (Focus Order)** and **WCAG 2.1.1 (Keyboard)** violation.
