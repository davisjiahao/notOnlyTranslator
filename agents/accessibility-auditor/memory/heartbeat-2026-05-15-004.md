#### P2 Fix: Radiogroup Arrow Key Navigation (`a016e8a`)

**Issue**: Both `GeneralSettings.tsx` (theme selector) and `AchievementGallery.tsx` (filter) used `role="radio"` inside `role="radiogroup"` but:
- No ArrowLeft/ArrowRight keyboard navigation between options
- All radios had `tabIndex` via default button behavior (no roving tabindex)
- Keyboard users could Tab to any radio but couldn't navigate the group per WCAG radio pattern

**Fix** (2 files, 34 insertions):
1. **GeneralSettings.tsx** — Added `onKeyDown` handler for ArrowLeft/ArrowRight, roving `tabIndex` (checked=0, unchecked=-1)
2. **AchievementGallery.tsx** — Same pattern for filter radiogroup

**WCAG Criteria**: 2.1.1 Keyboard, 2.4.3 Focus Order
