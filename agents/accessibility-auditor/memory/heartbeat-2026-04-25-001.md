## WCAG 2.1 AA 合规性审计结果

### 严重缺陷 (CRITICAL)

| 缺陷 | WCAG 标准 | 影响 | 文件位置 |
|------|-----------|------|----------|
| **Tooltip 无 aria 标记** | 4.1.2 Name, Role, Value | 屏幕阅读器无法识别 tooltip | `src/content/tooltip.ts` |
| **Highlighter 无语义标记** | 1.3.1 Info and Relationships | 翻译词汇无法被 AT 识别 | `src/content/highlighter.ts` |
| **Modal 无 aria-modal** | 4.1.2 | 对话框边界不明确 | 5+ modal 组件 |
| **无 focus trap** | 2.4.3 Focus Order | Modal 打开后焦点可逃逸 | 所有 Modal |
| **Toggle 无 role="switch"** | 4.1.2 | 开关状态不可感知 | `App.tsx` 多处 toggle |

### 高优先级缺陷 (HIGH)

| 缺陷 | WCAG 标准 | 影响 | 文件位置 |
|------|-----------|------|----------|
| **无 aria-live region** | 4.1.3 Status Messages | 加载/错误状态不通知 | tooltip loading/error |
| **Tab 无 role="tablist"** | 4.1.2 | 选项卡结构不明确 | `options/App.tsx` sidebar |
| **导航不移动 focus** | 2.4.3 | J/K 导航仅视觉高亮 | `navigationManager.ts` |
| **FloatingButton 无键盘支持** | 2.1.1 Keyboard | 仅鼠标操作 | `floatingButton.ts` |

### 中等缺陷 (MEDIUM)

| 缺陷 | WCAG 标准 | 影响 | 文件位置 |
|------|-----------|------|----------|
| **aria-label 仅 8 处** | 4.1.2 | 大量按钮无标签 | 全项目 |
| **无 role="alert"** | 3.3.1 Error Identification | 错误消息不通知 | tooltip error state |
| **无 skip links** | 2.4.1 Bypass Blocks | popup 无导航跳过 | `popup/App.tsx` |
| **用 span 而非 mark** | 1.3.1 | 高亮词汇语义缺失 | `highlighter.ts` |

### 现有合规项 ( positives)

- ✅ `aria-label="关闭"` 存在于 7 处 close 按钮
- ✅ `sr-only` 用于隐藏标签 (3处)
- ✅ `<nav>` 和 `<main>` 在 options 页面使用
- ✅ 键盘快捷键已注册 (Alt+T, Alt+Shift+T, Ctrl+Shift+Y)
- ✅ 键盘事件处理存在 (`tooltip.ts` keydown handler)

## 修复优先级建议

### P0 - 立即修复 (阻塞性)

1. **Tooltip aria 属性** - 添加 `role="tooltip"` + `aria-live="polite"`
2. **Modal focus trap** - 使用 `@react-aria/focus` 或手动实现
3. **Toggle role/aria-checked** - 所有开关按钮添加 `role="switch"` + `aria-checked`

### P1 - 本周修复

4. **aria-live regions** - 加载/错误/成功状态通知
5. **Tab pattern** - Options sidebar 完整 tablist/tab/tabpanel
6. **Navigation focus** - `navigateToNext()` 添加 `.focus()` 和 `scrollIntoView()`

### P2 - 下版本

7. **FloatingButton 键盘支持** - Enter/Space 打开面板
8. **Highlighter semantic** - 使用 `<mark>` + aria-describedby
9. **全局 aria-label 补全** - 所有 icon-only 按钮
